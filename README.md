# fin-rag · A股年报智能问答

面向 A 股上市公司年报与公告的文档问答系统：输入几百页、含复杂财务表格的 PDF，
精确回答财务与经营问题（营收构成、前五大客户、商誉、审计意见、分红方案等），
答案带引用溯源与页码定位。

**这不是一个 demo，是一个有评测报告、可部署、有性能数据的生产级系统。**

## 为什么做这个

- 解析最脏：合并财务报表是全领域最难的结构化问题——跨页表格、多级表头、
  万元/亿元单位混用、母公司/合并口径并存，解析层是本项目的核心技术壁垒
- 答案可验证：财务数字有唯一确定答案，golden set 可自动判分（数字准确率）
- 业务痛点真实：投研、信贷尽调、风控、券商 IT 每天都在处理年报公告

## 架构

```
年报PDF ──► 解析层(pdfplumber/PyMuPDF + 版面分析模型) ──► 结构化切分
   (巨潮资讯网)                                            │
用户提问 ──► 查询改写 ──┬─► BM25 关键词检索 ──┐            ▼
                       └─► bge-m3 向量检索 ───┤► RRF 融合 ► bge-reranker 精排
                                               │            │
                                               ▼            ▼
                                          引用溯源+页码 ◄── LLM 生成（云 API）
```

- 检索组件（embedding / rerank）本地 GPU 推理，生成走云 API（DeepSeek/Qwen/GLM），
  控制成本的同时保证答案质量——这是生产环境的典型混合架构

## 评测（项目的灵魂）

自建 golden set（目标 300 条，覆盖数字型/表格型/文本型问题），指标：检索 Top-K
召回率 / MRR、答案忠实度、**数字准确率**（数值误差 ≤0.5% 判对）。所有优化
（切分策略、混合检索、rerank、查询改写）必须有前后对比数据，记录在
`docs/eval-report.md`。

| 版本 | 变更 | Top5 召回率 | 数字准确率 | 忠实度 |
|------|------|------------|-----------|--------|
| v0 naive baseline | 固定 chunk + 纯向量 | 待测 | 待测 | 待测 |
